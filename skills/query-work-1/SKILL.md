# 查询众言工作记录

只查众言。只读，不改笔记。

## 环境变量

从当前进程的环境读取 `SWXSSKILL_OBSIDIAN_VAULT`。它是已登记的仓库目录名。为空时停下来，指出缺这个变量。

下文 `<vault>` 就是这个值。`vault=` 是第一个参数，原样传入：

```
obsidian vault="<vault>" <子命令> <参数>
```

Obsidian 处于运行中才能查询；若未运行，第一次调用会启动它。

## 先分类

先归类，再查该类。

| 类            | 用户在问                       | 去哪里                                                      |
| ------------- | ------------------------------ | ----------------------------------------------------------- |
| 需求          | 做到哪了、功能、需求、任务计划 | `任务.base` 视图 `众言项目-看板`，以及 `项目/众言/任务计划` |
| 历史 BUG 修复 | 报错、修复、某项目解决过的问题 | `项目/众言/问题排查` 下的全部笔记                           |
| 临时任务      | 临时事务、临时任务             | `项目/众言/临时事务`                                        |

对得上某一类时只查那一类。对不上或跨类时，三类都查，答案按这三类分开。同一条笔记只出现在它的目录所属的那一类：`任务计划` 归需求，`问题排查` 归历史 BUG，`临时事务` 归临时任务。用户明确在问需求时，`众言项目-看板` 里的临时事务保留在需求结果中。

完成：类别已经确定，或已经标成「三类都查」。

## 需求

```
obsidian vault="<vault>" base:query path="_resources/数据库/任务.base" view="众言项目-看板" format=json
obsidian vault="<vault>" search:context query="<关键词>" path="项目/众言/任务计划" limit=20
```

没有关键词时，看板结果就是需求列表，并列出 `项目/众言/任务计划` 下的笔记。

完成：看板和任务计划都已查过。

## 历史 BUG 修复

查 `项目/众言/问题排查` 下的全部笔记，不按 `status` 收窄。

```
obsidian vault="<vault>" search:context query="<关键词>" path="项目/众言/问题排查" limit=20
```

问题点名了某个项目时，先在 `众言.base` 里对上项目笔记，再查指向它的问题记录。视图按问题选用：客户项目用 `定制环境`，标准环境用 `SAAS环境`，功能模块用 `SAAS功能`。

```
obsidian vault="<vault>" base:query path="_resources/数据库/众言.base" view="定制环境" format=json
obsidian vault="<vault>" search:context query="<项目名>" path="项目/众言/问题排查" limit=20
```

项目笔记在 `项目/众言/环境大全` 或 `项目/众言/功能项目`。问题记录算命中的条件：`projects` 指向该笔记，或文件名带该项目名。

完成：问题排查目录已经覆盖；点了项目名时，项目笔记和对应问题记录都已列出。

## 临时任务

```
obsidian vault="<vault>" search:context query="<关键词>" path="项目/众言/临时事务" limit=20
```

完成：临时事务目录已经覆盖。

## 时间范围

用户说「最近、这周、本月」时用 `众言-30天`。范围超过 30 天时用 `众言-90天`。

```
obsidian vault="<vault>" base:query path="_resources/数据库/任务.base" view="众言-30天" format=json
```

结果仍按需求、历史 BUG、临时任务拆开。

完成：时间范围内的记录已按三类分开。

## 直接读取文件

目录根用 `vault info=path` 取得：

```
obsidian vault="<vault>" vault info=path
```

下面的路径都相对这个根。

```
项目/众言/
├── 任务计划/          需求
├── 临时事务/          临时任务
├── 问题排查/          历史 BUG
├── 环境大全/
│   ├── 标准环境/
│   └── 定制环境/      客户项目
└── 功能项目/          功能模块
```

## 典型示例

**需求。**「众言的筛选器做到哪了」

查 `众言项目-看板`，并在 `项目/众言/任务计划` 搜索「筛选器」。答案给出路径、`status`、`scheduled`。

**历史 BUG。**「爱尔眼科解决过什么问题」

对上 `项目/众言/环境大全/定制环境/爱尔眼科.md`，再列出 `问题排查` 里 `projects` 指向它、或文件名以 `爱尔眼科-` 开头的全部笔记。

**临时任务。**「众言最近有哪些临时事务」

查 `项目/众言/临时事务`，并用 `众言-30天` 补时间范围。落在 `临时事务` 的记入临时任务。

## 回答

按时间倒序。每条给出仓库相对路径、日期（`scheduled` 或文件名里的日期）、`status`、一句话内容。三类分开列。

完成：问到的每一类要么有列表，要么写明查过并且没有。
