# 固定块

## 范围

```markdown
## 范围

<这次管哪些功能点，一两句>
```

## 功能点

```markdown
## <功能点>

| 组件           | 效果         | 出现条件   | 操作条件   | 操作失败提示     | 说明         |
| -------------- | ------------ | ---------- | ---------- | ---------------- | ------------ |
| <页面上的名称> | <做成什么事> | <何时显示> | <何时可点> | <失败文案，可空> | <补充，可空> |
```

同一格里有多条约束时，用 `<br>` 分行。
